# Ex-4 – Scenario-Based Report Development Utilizing Diverse Prompting Techniques
## reg-no: 212224040213
## Objective

The goal of this experiment is to design and develop an AI-powered chatbot that can handle customer inquiries, provide support, and improve customer experience in a retail environment. Various AI prompting techniques are used to guide the chatbot in understanding customer queries and providing suitable responses.

## Aim

To create prompts using different AI prompting techniques for an AI-powered retail customer support chatbot and evaluate its ability to handle customer inquiries effectively.

## Algorithm

### Step 1
Identify the retail customer support scenario and define the chatbot's purpose.

### Step 2
Identify common customer queries such as product availability, order status, returns, refunds, and delivery.

### Step 3
Create prompts using different prompting techniques.

### Step 4
Provide the prompts to an AI chatbot and generate responses.

### Step 5
Analyze the generated responses based on accuracy, relevance, clarity, and helpfulness.

### Step 6
Compare the results obtained from different prompting techniques.

### Step 7
Prepare the final report based on the analysis.

## Prompt

### 1. Straightforward Prompt

**Prompt:**

> You are a retail customer support chatbot. Answer the customer's question clearly and politely.
>
> **Customer:** Where is my order?

**Expected Output:**

> Please provide your order ID so I can help you check the current status and estimated delivery date of your order.

---

### 2. Tabular Format Prompt

**Prompt:**

> Create a table showing common retail customer queries, suitable chatbot responses, and the expected action.

**Expected Output:**

| Customer Query | Chatbot Response | Expected Action |
|---|---|---|
| Where is my order? | Please provide your order ID to track it. | Check order status |
| Is this product available? | Yes, the product is currently available. | Check inventory |
| How can I return a product? | You can request a return through your order page. | Initiate return |
| When will I get my refund? | Refunds are generally processed after the returned item is verified. | Check refund status |
| Can I cancel my order? | Please provide your order ID to check cancellation eligibility. | Check cancellation status |

---

### 3. Preceding Question Prompt

**Prompt:**

> What is a retail customer support chatbot?
>
> What types of customer problems can it solve?
>
> How can an AI chatbot improve customer satisfaction?
>
> Based on these questions, explain how a retail chatbot should respond to a customer asking about a delayed order.

**Expected Output:**

> A retail customer support chatbot is an AI-powered system that helps customers with common questions and problems. It can handle order tracking, product availability, returns, refunds, cancellations, and delivery issues. It improves customer satisfaction by providing quick and consistent support. For a delayed order, the chatbot should politely apologize, ask for the order ID, check the order status, and provide the latest delivery information.

---

### 4. Missing Word Prompt

**Prompt:**

> A retail chatbot should provide ______ and helpful responses to customer queries.

**Expected Output:**

> **Accurate**

## Output

### Sample Customer Interaction

**Customer:**

> I received a damaged product. What should I do?

**Chatbot:**

> I'm sorry that you received a damaged product. Please provide your order ID and, if possible, upload a photo of the damaged item. We can then help you with the return or replacement process.

**Customer:**

> I want a replacement.

**Chatbot:**

> Sure. Once your order details are verified, we can help you initiate a replacement request according to the store's return policy.

## Analysis

| Evaluation Criteria | Result |
|---|---|
| Accuracy | High |
| Relevance | High |
| Clarity | High |
| Customer Friendliness | High |
| Response Speed | High |

The chatbot provides clear, polite, and relevant responses to common retail customer queries. Different prompting techniques help improve the structure and quality of the generated responses.

## Result

Thus, the AI-powered retail customer support chatbot was successfully designed using diverse prompting techniques. The prompts generated relevant, accurate, and customer-friendly responses, demonstrating how prompt engineering can improve AI-based customer support in a retail environment.
